# Credits

- **Project foundation:** NUS CS2103/T Duke/iP starter template and JavaFX tutorial structure.
  Original template contributors remain listed in the repository's `CONTRIBUTORS.md`.
- **AI collaboration:** OpenAI Codex assisted with JavaFX layouts, command presentation, error-handling
  improvements, JUnit tests, and documentation. The project owner selected the visual direction,
  response wording, supplied artwork, and reviewed the app manually.
- **Inter:** Rasmus Andersson and contributors. Bundled license:
  `src/main/resources/fonts/Inter-LICENSE.txt`.
- **Manrope:** Manrope project contributors. Bundled license:
  `src/main/resources/fonts/Manrope-LICENSE.txt`.
- **JavaFX, Gradle, Shadow, JUnit, and Checkstyle:** third-party runtime/build/test tools declared
  in `build.gradle`.
- **Music artwork and short lyric excerpts:** supplied by the project owner; associated with
  Lorde (Melodrama / Supercut / Liability), Olivia Rodrigo (SOUR / Brutal / 1 Step Forward,
  3 Steps Back), and Sabrina Carpenter (Never Getting Laid). Post Malone artwork is retained
  as an unused earlier asset. These are third-party creative works, not original WWaffle artwork.
- **Minion images:** supplied by the project owner; Minions characters are associated with
  Illumination/Universal. The screenshots and reaction images are not original WWaffle artwork.
- **Waffle and coffee avatars:** supplied by the project owner. Original image source has not
  been recorded in the project.

Before the public release, the project owner should fill in the original source links for supplied
images and confirm which assets belong in the public distribution. Attribution is not a claim
that a third-party asset has an open-source license.
